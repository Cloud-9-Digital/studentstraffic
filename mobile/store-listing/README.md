# Play Store listing assets

- `screenshots/` — five 1080×1920 phone screenshots (framed, with headings), in upload order 1–5.
- `en-US/short-description.txt` — max 80 characters.
- `en-US/full-description.txt` — max 4000 characters.

Remove the old phone screenshots in Play Console (Grow > Store presence > Main store listing > Phone screenshots) and upload these in order.
